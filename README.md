# 🎨 Terminal Theme — 多彩终端主题轮换系统

每个新终端窗口自动分配不同主题色（提示符标签 + 背景色 + Tab 标题），让多窗口工作时一眼区分。

> 配色来自 Tokyo Night 色板，8 种颜色自动轮换。

## 效果

打开多个终端窗口，每个窗口自动获得不同的主题色：

| 樱花粉 🌸 | 天空蓝 🔵 | 清新绿 🍀 | 薰衣草 💜 |
|----------|----------|----------|----------|
| 深海靛 🌌 | 琥珀金 ✨ | 玫瑰红 🌹 | 薄荷青 🌊 |

每个主题包含：
- 彩色提示符标签（名称 + emoji）
- 终端背景色（25% 主题色 + 75% 纯黑，护眼不刺眼）
- Tab/窗口标题（自动显示主题名 + 当前目录）
- ANSI 调色板同步（终端文字颜色跟随主题走）

## 兼容性

| 终端 | 背景色 | 提示符标签 | Tab 标题 | 说明 |
|------|--------|-----------|---------|------|
| **iTerm2** | ✅ | ✅ | ✅ | 已按设计适配 |
| **Kitty** | ✅ | ✅ | ✅ | 已按设计适配 |
| **Ghostty** | ✅ | ✅ | ✅ | 已按设计适配 |
| **WezTerm** | ✅ | ✅ | ✅ | 已按设计适配 |
| **Alacritty** | ✅ | ✅ | ❌ | 背景+标签可用 |
| **VS Code 终端** | ✅ | ✅ | ✅ | 通常可用 |
| **Qoder 终端** | ✅ | ✅ | ✅ | 通常可用 |
| **Windows Terminal** | ✅ | ✅ | ✅ | 需要 WSL + zsh |
| **macOS Terminal.app** | ❌ | ✅ | ✅ | 不支持 OSC 11 背景色 |

> 核心原理：使用 OSC 11 转义序列动态修改背景色。不支持 OSC 11 的终端会自动降级为仅显示彩色提示符标签。
>
> 注意：某些嵌入式终端、宿主应用内终端或伪终端可能不会暴露标准终端环境变量。安装脚本会默认尝试启用背景色；如果背景色未生效，可改用 iTerm2/Kitty/Ghostty/WezTerm，或手动调整 `~/.zshrc` 中的背景色配置。

## 前置要求

- **zsh**（macOS 默认就是，Linux 需要 `apt install zsh`）
- **git**（安装插件用）

以下会在安装过程中自动处理：
- Starship（提示符引擎，自动安装）
- zsh-syntax-highlighting（可选，自动安装）
- zsh-autosuggestions（可选，自动安装）

## 安装

```bash
# 先把仓库地址替换成你自己的 GitHub 地址
git clone https://github.com/<your-username>/terminal-theme.git
cd terminal-theme
bash install.sh
```

安装脚本会自动：
1. 检测你的 Shell 和终端类型
2. 安装 Starship（如果没有）
3. 可选安装 zsh 插件
4. 备份现有 `.zshrc`
5. 写入主题配置（根据终端能力启用背景色/标签/标题）

**安全说明：** 本项目会修改你的 `~/.zshrc`。安装前会自动备份；如果你的 shell 配置里有明文密钥或敏感环境变量，建议先迁移到独立文件（如 `~/.env.secrets`）后再安装。

**安装完成后，打开一个新终端窗口即可看到效果。多开几个窗口，每个都是不同颜色。**

## 卸载

```bash
cd terminal-theme
bash uninstall.sh
```

会自动清理所有配置并恢复默认，之前的 `.zshrc` 备份文件也会保留。

## 自定义

### 调整背景色深浅

编辑 `~/.zshrc`，找到 `混合比例` 那行，修改 `25` 这个数字：
- **20-25%** → 推荐值（有色调，不刺眼）
- **10-15%** → 更暗，色调微弱
- **30-40%** → 更亮，色调更明显

### 添加新主题色

在 `~/.zshrc` 中找到 5 个数组（`_PROMPT_FG`、`_PROMPT_BG`、`_PROMPT_TEXT`、`_PROMPT_ICON`、`_PROMPT_NAME`），在每个数组末尾同步添加新元素即可。

前景色规则：
- 浅色背景 → 用深色字 `1a1b26`
- 深色背景 → 用白色字 `ffffff`

### 重置轮换顺序

如果所有窗口颜色一样了：

```bash
rm -f /tmp/.zsh_prompt_counter_*
```

然后重新打开终端。

## 技术原理

```
~/.zshrc 底部配置
├── 主题定义：5 个并行数组（FG/BG/TEXT/ICON/NAME）
├── 窗口计数器：/tmp/.zsh_prompt_counter_UID（每个新窗口 +1，取模轮换）
├── 背景色混合：25% 主题色 + 75% 纯黑（OSC 11 转义序列）
├── ANSI 调色：基于 TEXT 数组自动映射 ANSI 15/7/9（OSC 4 转义序列）
├── Starship：每个终端独立配置文件（按 PID 区分，退出自动清理）
└── Tab 标题：OSC 1 + OSC 2 联动主题名 + 目录名
```

## 与 Claude Code 配合

如果你使用 Claude Code（Anthropic 的 CLI 编程工具），本主题会自动调整 ANSI 调色板，让 Claude Code 的对话文字颜色也跟随主题色变化，实现全终端统一配色体验。
